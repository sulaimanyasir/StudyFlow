# Student Semester Planner

A comprehensive web application designed to help students effectively manage their academic life. Built with modern web technologies including React, Vite, Tailwind CSS, and Express.

## Features

- **Student Dashboard**: A central hub for an overview of your academic progress.
- **Timetable Management**: View and organize your weekly class schedules.
- **Course & Exam Tracking**: Keep track of enrolled courses, assignments, and upcoming exam dates.
- **GPA Simulator/Calculator**: Calculate current and projected GPA to plan your academic goals.
- **Attendance & Grading**: Monitor attendance records and track grades across all subjects.
- **Admin Panel**: Manage institutional resources such as room data and course configurations.

## Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS 4, Motion (Animations), Lucide React (Icons)
- **Backend**: Express.js

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the application:
   ```bash
   npm run dev
   ```
   The development server will start at `http://localhost:3000` (or `http://0.0.0.0:3000`).

## Available Scripts

- `npm run dev` - Starts the Vite development server.
- `npm run build` - Builds the application for production.
- `npm run preview` - Previews the production build locally.
- `npm run lint` - Runs TypeScript type checking.
- `npm run clean` - Removes the build output and server files.
